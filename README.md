# Demic Ride

**Corporate Taxi Dispatch & Ride-Hailing Platform** for African transport operators.

Built with Next.js, Supabase, and Tailwind CSS. Deployed on **Render**.

🔗 **Live:** [ride.demicafrica.com](https://ride.demicafrica.com)
🔗 **Challenge Branch:** [finish-up-athon](https://github.com/Demic-Africa/demic-ride/tree/finish-up-athon)

---

## Features

- Ride booking
- Driver dispatch
- Operations dashboard
- Audit trail
- Cloud-hosted infrastructure
- **Telegram Alerts** - Real-time notifications for every booking
- **Multi-language Support** - English, Swahili, Kikuyu, Luo
- **Multi-channel Notifications** - SMS, Email, WhatsApp ready

---

## Technology Stack

- Next.js
- Supabase
- Tailwind CSS
- Render

## About

Demic Ride is a digital mobility and dispatch platform built to support 
corporate transport operations, passenger booking, centralized ride 
management, and driver coordination.

Developed and maintained by Demic Tours Africa.
