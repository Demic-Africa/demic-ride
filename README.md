# Demic Ride

Corporate taxi dispatch and ride-hailing platform developed by Demic Tours Africa.

---

## Features

- Ride booking
- Driver dispatch
- Operations dashboard
- Audit trail
- Cloud-hosted infrastructure

---

## Technology Stack

- Next.js
- Supabase
- Tailwind CSS
- Vercel

---

## Deployment

Live system:

https://demic-ride.vercel.app

## About

Demic Ride is a digital mobility and dispatch platform built to support
corporate transport operations, passenger booking, centralized ride
management, and driver coordination.

Developed and maintained by Demic Tours Africa.
